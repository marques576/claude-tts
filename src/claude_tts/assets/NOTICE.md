# Bundled reference voice

`reference-voice.wav` is a 16 second excerpt (00:40–00:56) of a LibriVox recording
that LibriVox releases into the **public domain** (CC0 1.0 / Public Domain Mark):

- Title: *The Purple Sapphire, and Other Posthumous Papers* (Christopher Blayre)
- Source: https://archive.org/details/purplesapphire_2502_librivox
- File used: `purplesapphire_00_blayre_128kb.mp3`
- License: http://creativecommons.org/publicdomain/mark/1.0/
- Processed with ffmpeg: mono, 24 kHz, 16-bit PCM, 16 s excerpt

It is only a convenient default voice for zero-shot voice cloning. It is not a
likeness of any real person's identity beyond what LibriVox published.
